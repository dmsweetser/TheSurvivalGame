# v1.26 — ROOT ACCESS

There is a door in the Bug Mall that was not there before, and it is not selling anything either. It is waiting for you to have done something worth writing down.

**THE SOURCE ROOM:** On the Mall's north wall stands a tenth stop: THE SOURCE. While your Trophy Case is still young, the door stays sealed under a plaque that keeps honest count — TROPHIES 1/3, say — because the room behind it is not a shop, a cabinet or a game. It is the game's own engine room. Earn any three trophies and the seal gives. Inside: humming racks, a terminal counter, and an exit mat, because even engine rooms observe the fire code.

**THE TERMINAL:** Sit down at the counter and the whole game opens up in front of you — every last source file, all 145 of them, filed under the same folders the game itself is built from. Bugs in one drawer. The Mall in another. The WAR! room has seventeen files and uses all of them. Browse the lot with keyboard, pad or fingertip. Open a file and you are reading the actual code the game is running, lowercase and all — the font learned lowercase for exactly this, and it has been waiting to show off.

And you can change it. With a keyboard the terminal is an editor: type, delete, rearrange, save. Your edits are kept — in the browser's own storage on the web, in a folder beside your saves in the app — and they are still there next session, marked with a star in the file list so you always know which pages are yours now. Changed your mind about everything? RESET STOCK sweeps the desk clean and puts the original game back, every file, no questions asked.

**LIVE TUNING:** Some of what you'd reach for first doesn't need a rebuild at all. A hundred and thirty-two of the game's working numbers sit on the live register: the difficulty tables the bug stats are figured from, weapon prices, upgrade prices, the Cart and Run medal thresholds, the beam numbers, the threat ratio — and, yes, the trophy count on the Source Room's own door, which can be set anywhere from zero to twenty by anybody already inside. Open a file that carries live values and the terminal offers TUNE: change a number, hit APPLY, and the game takes it on the spot, mid-session, no reload. Every value is checked against its honest range before it lands — type nonsense and the terminal refuses the whole batch and tells you why. Your tuned numbers persist like your edits do, and RESET STOCK returns every dial to the factory setting.

**THE REBUILD:** The rest of your edits — the logic, the behaviour, the parts that are code rather than numbers — want a compiler, and the native app has one. Press BUILD in the terminal and the host app takes your entire edited source tree, rebuilds the game from it on a worker thread, and serves the result from its own built-in web server: the page your browser guests load is now YOUR build of the game, changes and all. If the compile fails — it happens to the best of us, usually around a semicolon — the terminal shows you the compiler's own words about it, and the last good build stays served, untouched. A broken experiment never takes the game down. The app window itself keeps running the stock code, unbothered; it is the page it hands out that becomes yours. On the web build the terminal still does everything else — browsing, editing, tuning, saving — and BUILD will politely tell you it needs the host app for that trick. Your edits wait patiently in storage until they meet one.

**BANZAI WORLD, BY TOUCH:** One repair from the suggestion ledger. Inside Banzai World, the Start menu — RESUME, CONTROLS, LEAVE — used to answer only to keyboards and gamepads, which left touch players with no road to the CONTROLS panel at all. There is now a START chip on the Banzai touch controls, top-left where a thumb expects it, and the menu's rows take taps like every other row in the game. The village is reachable by every hand that plays it.

The door is sealed. The trophies are out there. You know what to do.

SQUASH BUGS. WEAR THE EVIDENCE.
