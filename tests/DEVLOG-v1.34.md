# v1.34 — THE FINGER IS HEARD

A one-bug hotfix, aimed at the exact spot a commander's finger lands.

**THE WALLS LISTEN NOW.** v1.33 taught WAR! commanders to drag out a whole firewall run and pass verdict on it with a tap — except the tap never arrived. The drag hand grabbed every resting finger first, mistook your APPROVE for the start of a brand-new drag anchored on the button itself, and then read the release as a one-segment wall order in the middle of nowhere — refused, naturally, for being nowhere. The preview died, the run went unbuilt, and the commander fumed. (Our own test rig tapped like a machine — down and up inside a single frame — so it never once saw what every human finger did.)

Now, while a run stands awaiting its verdict, the drag keeps its hands off: the chips own the field. APPROVE builds the run for its one honest charge, CANCEL walks away free, Enter and the pad's A still approve as before, and a plain rested tap with the FIREWALL armed still plants a single wall exactly as designed. The rig has learned to tap like a person, too — finger down, a breath, finger up — so this door stays nailed open.

Nothing else moved. No balance, no prices, no new tricks — just the button hearing the finger.
